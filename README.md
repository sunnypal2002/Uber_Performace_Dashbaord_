# Uber_Performace_Dashbaord_
🚖 Uber Rides &amp; Revenue Analysis Dashboard
<Br>

A Power BI dashboard built to dig into Uber's booking, revenue, and customer data across different vehicle types — Auto, Bike, Go Mini, Go Sedan, Premier Sedan, and Uber XL. The idea was to take a messy dataset and turn it into something a business team could actually use to spot trends, catch problem areas, and make decisions.
